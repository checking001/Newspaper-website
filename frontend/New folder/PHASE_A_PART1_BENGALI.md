## 📥 সেটআপ - 3 ধাপ

### **ধাপ 1: ফাইল কপি করুন (2 মিনিট)**

ডাউনলোড করা ফাইলগুলি আপনার প্রজেক্টে কপি করুন:

```bash
cp design-globals.css frontend/app/globals.css
cp theme-config.ts frontend/lib/theme.ts
cp fonts-setup.css frontend/app/fonts.css
```

### **ধাপ 2: Layout.tsx আপডেট করুন (5 মিনিট)**

`frontend/app/layout.tsx` এ যোগ করুন:

```typescript
import './globals.css';      // যোগ করুন
import './fonts.css';        // যোগ করুন

export default function RootLayout({ children }) {
  return (
    <html lang="bn">          {/* বাংলায় পরিবর্তন করুন */}
      <body>
        {children}
      </body>
    </html>
  );
}
```

### **ধাপ 3: বিল্ড এবং পরীক্ষা করুন (10 মিনিট)**

```bash
cd frontend
npm install
npm run build
npm run dev
```

যান: **http://localhost:3000**

✅ কোনো ত্রুটি না থাকলে → **সম্পূর্ণ!**

## 🔧 CSS ভেরিয়েবল উদাহরণ

